# HyperPosition

HyperPosition is a futuristic portfolio-intelligence landing page for Hyperliquid traders. The current implementation focuses on the Portfolio Time Machine concept: replaying trade decisions, comparing alternative outcomes, and understanding portfolio risk before the next move.

## UI

The React application lives in [`UI`](./UI).

### Run locally

```bash
cd UI
npm install
npm run dev
```

### Production build

```bash
cd UI
npm run build
```

## Current features

- Responsive React landing page
- Dark and light themes
- Animated trade-replay timeline
- Hyperliquid co-branding
- Portfolio metrics and alternative-outcome cards
- Flow Radar, Risk Simulator, and Smart Execution sections
